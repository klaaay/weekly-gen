### [](https://www.a16z.news/p/you-are-not-a-model-dont-price-per)

**原文标题**: [You are not a model. Don’t price per token.](https://www.a16z.news/p/you-are-not-a-model-dont-price-per)

overview summary  
本文主張 AI 應用不應沿用模型層的「按 token 計價」模式，而應根據所能衡量、歸因與防禦的最高價值層來訂價：賣模型存取按 token、賣完成的工作用點數（credits）、賣可歸因的商業成果則按成果計價。文中以問卷、Clay 案例等說明 token 計價的缺點，並提出點數系統設計原則與混合訂價的彈性。

- 📉 Token 計價源自模型層（如 OpenAI API），但套用到應用層會把供應商的成本結構轉嫁給客戶，並將產品價值錨定在成本持續下降的單位上，是常見的錯誤。  
- 🏆 正確訂價原則：應在可可靠衡量、歸因與防禦的「最高價值層」訂價——模型存取按 token、應用工作按可辨識的價值單位（常用點數）、明確成果按結果計價。  
- 🔍 客戶要求看 token，其實是想要「可比性」或「成本控制」；但跨產品比較 token 不具真實意義，預測 token 消耗也遠比預測工作量困難，反而增加摩擦。  
- 🎯 應用層的價值單位因產品而異：帳戶研究 agent 賣「完成簡報」、coding agent 賣「實作變更」、數據平台賣「查詢/管線」；應問客戶已理解的價值單位是什麼。  
- 💳 點數應「對應工作價值」而非「隱藏 token」：強式點數系統用直觀的難度分級（小 bug 修正<多檔案功能、單條款摘要<整份合約審閱），並做到抽象基礎設施、解釋相對努力、提供商業彈性。  
- 🛡️ 點數能保護毛利：將「工作值多少錢」與「完成工作成本多少」分開，即使模型成本下降，供應商仍可保有部分利潤空間，不必隨成本曲線降價。  
- 🧩 可採用混合訂價：座位（存取）、點數（變動工作）、token 轉嫁（特別昂貴/波動的模型）、成果費用（歸因清晰時）並存，但須避免在錯誤層級使用錯誤計量器。  
- 🚀 成果明確時應轉向成果計價：例如已解決的客服對話、合格潛在客戶、預約會議、處理完成的理賠；若無法乾淨歸因，則用點數計價工作單位。  
- 📚 Clay 案例：曾因 2022 年 Pro 方案點數誤訂而虧損多年；後來分離「Data Credits」（第三方資料）與「Actions」（編排工作），並對高波動推理模型以原價轉嫁 token 成本，為分層混合訂價典範。  
- ⚠️ 結論：Token 計價會把對話導向持續下滑的成本曲線，不利於凸顯應用持續上升的價值；應讓客戶看到「工作完成度」與「容量去向」，但報表透明不等於把帳單與成本計量表綁在一起。

### [谷歌是如何让工程师接受管理的](https://hbr.org/2013/12/how-google-sold-its-engineers-on-management)

**原文标题**: [How Google Sold Its Engineers on Management](https://hbr.org/2013/12/how-google-sold-its-engineers-on-management)

Google 相信“用数据说话”的管理变革——通过 Project Oxygen 项目分析、定义、培养并奖励优秀经理行为，成功让崇尚技术、质疑管理价值的工程师接受了“管理”本身。

- 💥 文化挑战：Google 是一个“由工程师为工程师”建立的高度技术文化公司，早期许多工程师认为管理分散注意力、具有破坏性；创始人曾尝试完全扁平化，但很快因事务混乱而恢复部分管理层。
- 🗂 精简设计：Google 如今有超过 37000 名员工，但只有 5000 名管理者，并有意识地让工程师经理直接带 30 人，从而限制微观管理，给员工更多自主创新空间。
- 🔑 用数据做说服：由于公司文化不看重头衔和命令，Google 决定用内部决策同款的方法——严格的数据和分析，来证明经理的价值，而非强制推行指令。
- 📉 Project Oxygen 启动：2009 年，Google 的人力分析团队发起“氧气计划”，甚至先试图证明“经理不重要”，却基于数据失败了；分析表明，即使微小的经理质量提升也能显著影响员工留任和幸福感。
- 💬 识别关键行为：通过访谈高低分经理、分析调查与评语，项目识别出高效经理共有的八项行为，例如“充分授权而不微观管理”，还包括给工程师提供职业发展指导、清晰沟通、协助消除阻碍等。
- 📋 反馈与调查：Google 设计出专门的向上反馈工具（UFS 和 TMS），强调匿名、保密和“自我发展”而非绩效惩罚，让经理和团队都能开诚布公地讨论改进点。
- 🧠 培训与课程：围绕八项行为开展实用培训，如“愿景班”让管理者练习为团队创作故事和方向，并开设新经理工作坊、全球在线课程，确保管理能力可持续提升。
- 🏆 奖励与晋升：Google 将八项行为融入“优秀经理奖”的评选标准，并作为晋升重要参考，例如最后一轮晋升副总裁的董事中，有 10% 曾是该奖得主。
- 📊 可衡量成果：2010 至 2012 年间，管理反馈好感中位数从 83% 上升至 88%，尤其低分经理提升最大；数据也显示经理评分不太会因负面绩效评价被报复，因为行为是否兑现、是否一致很难伪装。
- ⚠️ 持续挑战：项目依赖员工自愿参与调查，有“评估疲劳”风险；同时优秀经理行为在高管层、财务利润层面的因果影响仍难定论，未来需要更深入的观察与人格分析来继续优化。
