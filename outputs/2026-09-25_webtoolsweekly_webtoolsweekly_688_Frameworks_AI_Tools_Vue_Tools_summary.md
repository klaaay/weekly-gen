### [](https://github.com/apinanaivot/IKEA-3D-Model-Download-Button)

**原文标题**: [GitHub - apinanaivot/IKEA-3D-Model-Download-Button: Adds ability to download models from IKEA website · GitHub](https://github.com/apinanaivot/IKEA-3D-Model-Download-Button)

这是一个 Tampermonkey 用户脚本，可在 IKEA 商品页添加“Download 3D”按钮，方便下载 .GLB 格式的家具与装饰 3D 模型，用于个人家装规划与可视化，并支持多语言站点和自动命名。

- 🛠️ 项目为 GitHub 仓库 apinanaivot/IKEA-3D-Model-Download-Button，核心文件是 ikea-3d-model-downloader.user.js。
- ⭐ 仓库热度约 1.5k Star、63 Fork、14 Watchers，另有 7 Issues、0 Pull Requests、37 Commits。
- ⬇️ 脚本会在 IKEA 商品页的“View in 3D”按钮旁新增“Download 3D”按钮。
- 🌍 支持 IKEA 不同语言版本的网站。
- 🏷️ 下载文件自动按“[Product Name] - [Color].glb”格式命名。
- 🧊 下载的 .GLB 文件可用 Blender 等 3D 软件打开。
- 🏠 适合在购买前把家具放入自己的 3D 家装规划软件中试用。
- 🔧 安装需先装 Tampermonkey 扩展，再通过链接安装脚本，或把 user.js 内容粘贴到新脚本中并保存启用。
- 💻 使用 Chrome、Edge、Opera 等 Chromium 浏览器时，需开启开发者模式。
- 📌 使用方法：打开含“View in 3D”的 IKEA 商品页，点击“Download 3D”即可下载。
- ❓ 若按钮不出现：确认商品有 3D 模型并刷新；也可尝试 Ctrl + Alt + D；仍无效可提交 bug report。
- ⚠️ 免责声明：仅供个人家装规划与可视化，需遵守 IKEA 服务条款；作者不对滥用或违规负责。
- 🗓️ 更新：2026-01-30 进行了 Bugfix。
