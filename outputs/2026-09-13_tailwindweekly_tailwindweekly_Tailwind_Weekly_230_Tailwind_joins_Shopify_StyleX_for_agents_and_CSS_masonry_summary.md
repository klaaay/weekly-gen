### [你需要了解的CSS颜色插值 | CSS](https://css-tricks.com/what-you-need-to-know-about-css-color-interpolation/?ref=tailwindweekly.com)

**原文标题**: [What You Need to Know About CSS Color Interpolation | CSS-Tricks](https://css-tricks.com/what-you-need-to-know-about-css-color-interpolation/?ref=tailwindweekly.com)

颜色插值是指在两个颜色点之间计算中间颜色的过程，可用于创造新颜色、漂亮调色板、更佳渐变和平滑过渡。文章由 Sunkanmi Fafowora 于 2025 年 9 月 5 日发布，系统讲解 CSS 颜色插值的使用场景、颜色空间、色相插值方法，以及它在渐变、color-mix() 和动画中的实际价值。

- 🎨 CSS 中许多功能支持颜色插值：所有渐变函数、color-mix()、animation、transition、filter，以及相对颜色语法中的函数。
- 🧮 渐变和 color-mix() 支持正式语法：`in <color-space> [shorter|longer|increasing|decreasing hue]`；`in` 后接插值方法，第二项是颜色空间，第三项可选色相插值方法。
- 📐 矩形颜色空间用笛卡尔坐标表示颜色，例如 sRGB、lab、oklab、xyz；极坐标颜色空间呈圆柱形，例如 hsl、hwb、lch、oklch。
- 🧭 极坐标颜色空间中的色相是循环角度，因此 CSS 提供 shorter、longer、increasing、decreasing 四种色相插值方式。
- ⏱️ shorter 是默认值，走两个色相点之间较短路径；longer 走较长路径，类似在时钟上选择顺/逆时针方向。
- 🔁 increasing 总是按增加角度/顺时针方向插值，decreasing 总是按减少角度/逆时针方向插值；到达边界时会回绕。
- 🌈 实际应用包括创建更丰富渐变，例如在 conic-gradient() 中让色相平滑绕中心过渡。
- 🧪 color-mix() 可在不同颜色空间内混合颜色，并可结合 longer hue 等色相插值，产生独特混合结果。
- 🎞️ 动画可在两个颜色之间插值，展示中间所有过渡颜色；例如 @keyframes 从 oklch 深粉过渡到冷蓝。
- 📚 参考资源包括 Eric Portis 的 Okay, Color Spaces、ColorAide 颜色插值文档、CSS Color Module Level 4，以及 Chris Brunell 的 Interpolating Colors。
