- 👶 问题 2：把 Provider 写成包装 children 的独立组件，自身状态变化不会带动整个子树重渲染（children 作为 prop 天然隔离）。
- 🎯 问题 3：用 ref 技巧让 actions 保持稳定，效果类似 React 的 useEvent/useEffectEvent，避免因为闭包依赖导致子组件频繁重渲染。

- 🚀 用命名 hook 而非内联函数，是为兼容 React Compiler 自动记忆化，并让 eslint-plugin-react-hooks 正确检查 store 内部规则。
- ⚡ 性能取决于选择器精度；示例中 SubmitButton 只使用稳定 actions，因此输入时完全不重渲染。
- 📏 库仅 1.4kB（min+gzip），零依赖，基于 React 18+ 的 useSyncExternalStore；作者在大型项目实践中全应用只需 4 个 context。

手势回调与事件机制概述：本文档介绍了 React Native Gesture Handler 中手势状态转换与回调函数的完整流程，涵盖手势事件回调、底层触摸事件回调、事件对象结构及关键属性，并说明了与 Reanimated 的集成关系。

- 🧭 每个 handler 实例在任意时刻都处于某个状态，状态会因触摸事件或系统条件而改变，可通过手势回调监听状态转换。

- 🖐️ `onBegin`：handler 开始识别手势时触发，保证之后会有 `onFinalize`。
- ✅ `onActivate`：达到手势激活条件时触发，保证之后会有 `onDeactivate`。
- 📈 `onUpdate`：手势激活后，每次指针状态变化（通常为移动）时触发。
- ⏹️ `onDeactivate`：handler 停止识别手势时触发（仅在手势已激活的情况下），在 `onFinalize` 之前调用；事件对象含 `canceled` 属性表示是否被中断。
- 🔚 `onFinalize`：handler 停止识别时触发，无论是否激活；`canceled` 为 true 表示未激活或被打断，false 表示成功完成并在 `onDeactivate` 后立即调用。
- 👇 `onTouchesDown`：新指针触屏时触发，事件可能包含多个指针（批量处理）。
- ✋ `onTouchesMove`：指针在屏幕上移动时触发，可能包含多个指针。
- ☝️ `onTouchesUp`：指针离开屏幕时触发，可能包含多个指针。
- 🚫 `onTouchesCancel`：指针不再有后续信息时触发（手势结束或中断），可能包含多个指针。
- 📦 `GestureEvent`：包含通用属性（`handlerTag`、`numberOfPointers`、`pointerType`）以及各手势特有的数据。
- 📄 `GestureEndEvent`：在 `GestureEvent` 基础上扩展 `canceled` 属性，用于 `onDeactivate` 和 `onFinalize`。
- 🧩 `TouchEvent`：携带原始触摸事件信息，包含 `eventType`、`changedTouches`、`allTouches`、`numberOfTouches`、`pointerType`。
- 🎯 `TouchData`：描述单个触摸，含 `id`（用于跨事件追踪触摸）、`x`/`y`（相对视图坐标）、`absoluteX`/`absoluteY`（相对窗口坐标，推荐用于视图发生变换时）。
- ⚠️ 不要依赖 `changedTouches` 或 `allTouches` 数组中的排列顺序，应使用 `id` 属性追踪单独的触摸。

pnpm 11.20 发布，重点修复多注册表安装时的包替换风险，将命名注册表来源写入 lockfile；同时新增内置 `npmjs:` 别名，并修复代理配置、`pnpm rebuild` 安全性等问题，还优化了依赖解析性能。

- 🔒 安全修复：命名注册表解析的包现在以 `<name>@<registryName>:<version>` 形式记录在 lockfile 中，避免不同注册表提供同名同版本时被错误合并或替换。
- 📦 新增内置 `npmjs:` 别名，无需配置即可解析到 `https://registry.npmjs.org/`，并可通过 `namedRegistries` 覆盖为镜像或代理地址。
- ⚠️ 使用命名注册表的项目，下次非冻结安装会产生 lockfile 变更；团队应统一升级到该版本或更新版本，避免旧版本将 lockfile 改回旧格式。
- 🚫 删除 lockfile 引用的注册表别名会报 `ERR_PNPM_MISSING_NAMED_REGISTRY`；别名若与 `file`、`link`、`workspace`、`npm` 等保留前缀冲突会报错拒绝。
- 🛡️ `pnpm rebuild` 现在会拒绝包含路径穿越包名的恶意 lockfile，例如 `../../../escaped@1.0.0`，防止脚本在虚拟存储外执行。
- 🔧 空的代理设置（如 `HTTP_PROXY=` 或 `proxy=`）不再导致安装失败；`proxy=false` 会明确关闭代理，而不是被当作代理主机名。
- ⚡ 依赖解析速度提升：`minimumReleaseAge` 下每个 packument 只过滤一次，并复用已解析的 semver 版本和范围。
- 🧩 其他修复：`pnpm licenses` 和 `pnpm sbom` 区分来源；tarball URL 匹配顺序更稳定；pnpm 12+ 不再错误固定 `@pnpm/exe` 依赖。
